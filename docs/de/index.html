BackupFlow Hilfe

BackupFlow sichert Fotos, Videos und Dateien von deinem iPhone auf deinem eigenen Server – einem NAS, einem Heimserver oder deiner persönlichen Cloud. Ohne Abo und ohne fremde Cloud.

Was du brauchst

  • Einen Server, der FTP, SFTP oder WebDAV unterstützt. Die meisten NAS-Geräte (z. B. Synology oder QNAP) und persönliche Clouds wie Nextcloud unterstützen mindestens eines davon.
  • Die Serveradresse, einen Benutzernamen und ein Passwort.
  • Steht der Server in deinem Heimnetz, tippe auf Erlauben, wenn iOS nach dem Zugriff auf das lokale Netzwerk fragt.

Erstes Backup einrichten

  1. Tippe in der Backup-Zentrale neben Gespeicherte Server auf Hinzufügen.
  2. Wähle die Verbindungsart (FTP, SFTP oder WebDAV) und gib Serveradresse, Benutzername und Passwort ein.
  3. Tippe auf Verbindung testen, um zu prüfen, ob alles stimmt.
  4. Wähle unter Quelle die Fotomediathek (Fotos, Videos oder beides) oder tippe auf Ordner auswählen, um einen Ordner aus der Dateien-App zu wählen.
  5. Gib einen Zielordner auf dem Server ein oder tippe auf Remote-Ordner durchsuchen.
  6. Wähle einen Zeitplan und tippe auf Aufgabe speichern. BackupFlow bietet an, das erste Backup sofort zu starten.

Nach dem ersten Backup werden nur neue oder geänderte Dateien übertragen – spätere Backups sind daher viel schneller.

Automatische Backups

Wähle, wie oft gesichert wird: Manuell, Alle paar Stunden, Täglich, Wöchentlich oder Monatlich.

Du kannst auch festlegen, wann ein Backup laufen darf:

  • Wi-Fi erforderlich: nutzt nie mobile Daten.
  • Externe Stromversorgung erforderlich: läuft nur, während das iPhone lädt.
  • Erlaubtes Zeitfenster verwenden: zum Beispiel nur nachts.
  • Minimaler Akkustand (unter Einstellungen › Akkueinstellungen): überspringt Backups bei niedrigem Akku.

Ist eine Bedingung nicht erfüllt, wartet das Backup und startet, sobald sie erfüllt ist. Um eine Aufgabe vorübergehend anzuhalten, öffne sie und tippe auf Planung pausieren.

Gelöschte Dateien

Lege unter Löschrichtlinie fest, was auf dem Server passiert, wenn du etwas auf dem iPhone löschst:

Spiegeln (Standard)
Der Server bleibt eine exakte Kopie der Quelle. Auf dem iPhone gelöschte Dateien werden auch auf dem Server gelöscht.
Nur hinzufügen
Auf dem Server wird nie etwas gelöscht.
Löschen archivieren
Nichts wird gelöscht. Entfernte Dateien werden in einen datierten Ordner .backupflow_archive auf dem Server verschoben.

Du willst nach dem Backup Platz auf dem iPhone schaffen? Wechsle zu Nur hinzufügen oder Löschen archivieren, bevor du etwas löschst.

Backups im Hintergrund

iOS entscheidet, wann Apps im Hintergrund arbeiten dürfen. Ein geplantes Backup startet daher nicht immer auf die Minute genau. Zur geplanten Zeit startet BackupFlow das Backup oder sendet eine Mitteilung. Tippe auf Jetzt starten, um zu beginnen.

Bricht iOS ein Backup vorzeitig ab, öffne BackupFlow – es geht weiter. Bereits übertragene Dateien werden übersprungen.

Halte das iPhone bei einem großen ersten Backup im WLAN und am Strom.

Backup-Verlauf

Deine letzten Backups erscheinen in der Backup-Zentrale. Tippe auf Alle anzeigen für den vollständigen Backup-Verlauf. Jeder Eintrag zeigt die Anzahl der Dateien, die Gesamtgröße und die Dauer. Du kannst ihn auch als Bericht teilen.

Wie lange der Verlauf aufbewahrt wird, legst du unter Einstellungen › Verlaufsaufbewahrung fest.

Zusätzlicher Schutz

  • Uploads prüfen: kontrolliert, dass jede Datei unbeschädigt auf dem Server angekommen ist.
  • iCloud-Objekte bei Bedarf laden: sichert auch Fotos und Videos, die nur in iCloud liegen.
  • SFTP: BackupFlow merkt sich deinen Server bei der ersten Verbindung und warnt dich, wenn sich seine Identität ändert.

Problemlösung

Ich kann keine Verbindung zum Server herstellen.
Prüfe Adresse, Port, Benutzername und Passwort. Übliche Ports: FTP 21, SFTP 22, WebDAV 443. Bei einem Server zu Hause muss das iPhone im selben WLAN sein und unter iPhone-Einstellungen › Datenschutz & Sicherheit › Lokales Netzwerk Zugriff haben.
Ein geplantes Backup ist nicht gelaufen.
Prüfe die Bedingungen der Aufgabe (WLAN, Strom, Zeitfenster, Akku) und ob Mitteilungen für BackupFlow erlaubt sind. Öffne die App, um ein wartendes Backup zu starten.
Einige Fotos fehlen.
Aktiviere iCloud-Objekte bei Bedarf laden. Mit iCloud-Fotos liegen viele Originale nur in iCloud.
Dateien sind von meinem Server verschwunden.
Die Aufgabe nutzt vermutlich Spiegeln. Wechsle zu Nur hinzufügen oder Löschen archivieren.
Ich sehe eine SFTP-Sicherheitswarnung.
Die Identität des Servers hat sich geändert. Das ist normal, wenn der Server neu installiert oder ersetzt wurde. Andernfalls frage vor dem Fortfahren die Person, die den Server verwaltet.

Datenschutz

Deine Dateien gehen direkt vom iPhone auf deinen eigenen Server. BackupFlow hat keine eigenen Server, sieht deine Dateien nie und sammelt keine Daten. Passwörter werden sicher auf deinem Gerät gespeichert.

Einstellungen › Alle Daten zurücksetzen entfernt alle Aufgaben, den Verlauf und gespeicherte Passwörter von diesem Gerät. Dateien auf deinen Servern bleiben unberührt.
